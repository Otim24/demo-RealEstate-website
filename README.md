# demo-RealEstate-website

A responsive multi-page real estate demonstration website for **Demo Real Estate** built with **Astro 5** and **Tailwind CSS v4**.

## Features

- Multi-page Astro architecture with smooth View Transitions (`ClientRouter`) and scroll-triggered section animations
- Property portfolio with Ugandan Shilling (`UGX`) valuations, category filtering, and budget filtering
- Dedicated property dossier pages, About page, Market Journal essays, and consultation inquiry form
- Floating and contextual WhatsApp agent concierge (`+256` Uganda advisory desks)
- Responsive layout optimized for mobile, tablet, and desktop viewports

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
